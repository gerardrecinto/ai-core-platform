ai-core-platform

One governed way for engineers to use AI assistants. The gateway checks who is asking, what data they may send and where it may go, then routes with fallback and audits every call. Approved tools are served over MCP and can queue on-prem jobs as the requesting engineer.

Decisions and trade-offs

Design-only: never run in production.

ChoseOverWhyCostsFlip when
Gateway enforces policy, tools only advisePolicy in each toolOne place to audit, one place to fix a leak.The gateway is on the critical path, so it needs HA and its own on-call.Tools need different policy per team. Move rules to a policy engine such as OPA.
Role ceiling and provider ceiling must both cover the data classOne ceiling at the roleA permissive role cannot send confidential data to a commercial API.More configuration, and a mislabeled prompt still goes through.A classifier labels data reliably. Then derive the class instead of trusting the caller.
Self-hosted first for confidential dataCheapest firstIP stays in-house, and it is the cheapest option in the lab anyway.Needs GPUs and an on-call owner for the model host.Bedrock in your account meets the IP review. Then simplify to one provider.
Pinned manifest digest on every toolVersion tags onlyA swapped entrypoint after approval fails the call.Each change needs a new version and a new approval.Tools ship from a signed internal build. Then verify the signature instead.
Ticket per job, run as the requesterA shared service account on-premAudit shows a person, and file permissions already apply.Needs a user mapping on every on-prem host.Hosts have no personal accounts. Then use a short-lived delegated credential.

Limits

Mock model providers and synthetic identities. No real Entra ID, Bedrock, vLLM, VMware vSphere, LSF or EDA tools. The JWT code is a lab implementation; production uses a vetted library and a real JWKS endpoint. Helm, Terraform, Ansible and the image build are validated in CI and have never been applied. Claude Code and VS Code config files are untested in those clients.
